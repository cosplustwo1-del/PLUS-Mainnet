# Security Policy

## Supported Versions

Currently, the PLUS Mainnet is in Private Beta. Only the following versions are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |
| < 0.8.x | :x:                |

## Reporting a Vulnerability

Security is our highest priority. If you discover a vulnerability in the PLUS Mainnet Core Node, the PRC20 standard, or the matching engine, please **DO NOT** create a public GitHub issue.

Instead, please report the vulnerability privately via our Bug Bounty Program.

### Bug Bounty Tiers
- **Critical (L1 Node Consensus Halt / Remote Code Execution)**: Up to $250,000 USD
- **High (Smart Contract Logic Flaw / Fund Loss)**: Up to $100,000 USD
- **Medium (Denial of Service / RPC Crash)**: Up to $20,000 USD
- **Low (UI/UX Glitch in Explorer)**: Up to $2,000 USD

Contact our security team directly: `security@plusmain.net`.

We will acknowledge receipt of your vulnerability report within 24 hours and strive to send you regular updates about our progress.
